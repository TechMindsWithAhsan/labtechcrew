# Product screenshots

Real screens from real builds. Nothing else.

Structure: `public/shots/<case-study-slug>/<descriptive-name>.png`

Register them in `lib/data/work.ts` under the case study's `shots: []`.
Run `npm run check:shots` to see which case studies are still missing them.

NEVER put stock photography, third-party client logos, team headshots or
AI-generated art in here. See IMAGES-FOR-META-ADS.md for why.
